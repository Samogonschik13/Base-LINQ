
# Учебный шаблон: Изучение LINQ & Entity Framework Core

Данный проект представляет собой шаблон-песочницу для освоения технологии **LINQ** в связке с ORM **Entity Framework Core** и встраиваемой базой данных **SQLite**.

Проект разработан для локального запуска на ПК: он **не требует установки MS SQL Server**, создания локальных служб или ручного наката миграций. База данных создается и наполняется автоматически при первом старте.


## Архитектура и структура проекта

```text
UniversityLinqTemplate/
│
├── Models/                 # Слой сущностей (Таблицы БД)
│   ├── Group.cs               # Группы студентов
│   ├── Student.cs             # Студенты (связь с группой)
│   ├── Course.cs              # Учебные предметы
│   └── Grade.cs               # Оценки (таблица связей студент-курс)
│
├── Data/                   # Слой доступа к данным
│   ├── UniversityContext.cs   # Контекст БД (настройка подключения к SQLite)
│   └── DbInitializer.cs       # Первичная генерация БД и сидирование (наполнение) данными
│
├── Queries/                # Слой бизнес-логики и запросов
│   └── LinqDemos.cs           # Коллекция типовых LINQ-запросов (от простых к сложным)
│
├── Program.cs              # Точка входа: вызов инициализации и запуск демонстраций
├── .gitignore              # Исключение временных папок (bin, obj, .vs) и файла БД
└── README.md               # Документация и инструкция
```

## Быстрый запуск

1. Склонируйте репозиторий найдя в главном окне кнопку клонирования репозитория:
   ```bash
   https://github.com/odium22/Base-LINQ
   ```
2. Откройте файл `.sln` (или `.slnx`) в **Visual Studio**.
3. Нажмите комбинацию **`Ctrl + F5`** (Запуск без отладки).
4. Программа автоматически:
   * Проверит наличие базы SQLite и создаст файл `university.db` в папке сборки.
   * Наполнит базу начальными тестовыми данными.
   * Выполнит 5 категорий LINQ-запросов и выведет результат в консоль.



## Руководство по адаптации: ЧТО и ГДЕ менять под свою тему

Каждый студент должен адаптировать этот каркас под свою индивидуальную предметную область (например: *Автосервис, Интернет-магазин, Библиотека, Отель, Склад, Больница*).

### Шаг 1. Папка `Models/` - Проектирование своих сущностей
1. Удалите(замените или переработайте) имеющиеся классы (`Student.cs`, `Group.cs`, `Course.cs`, `Grade.cs`).
2. Создайте **минимум 3 - 4 свои сущности**.
3. Обязательно реализуйте между ними **связи** (внешние ключи и навигационные свойства).

> **Пример для темы «Автосервис»:**
> * `Car.cs` (`Id`, `Brand`, `LicensePlate`, `Year`, `ClientId`, навигационное свойство `Client`)
> * `Client.cs` (`Id`, `FullName`, `Phone`, список авто `List<Car>`)
> * `ServiceOrder.cs` (`Id`, `Date`, `TotalCost`, `CarId`, `Car`)


### Шаг 2. Файл `Data/UniversityContext.cs` - Регистрация таблиц
1. Переименуйте контекст под свою тему (или оставьте имя, если не хотите менять зависимости).
2. Замените наборы таблиц `DbSet<...>` на свои новые модели:
```csharp
public DbSet<Car> Cars => Set<Car>();
public DbSet<Client> Clients => Set<Client>();
public DbSet<ServiceOrder> ServiceOrders => Set<ServiceOrder>();
```
3. В методе `OnConfiguring` можно поменять название файла БД (например, `"Data Source=autoservice.db"`).


### Шаг 3. Файл `Data/DbInitializer.cs` - Генерация тестовых данных
1. Очистите метод `Initialize`.
2. Создайте тестовые записи для ваших сущностей и добавьте их в базу через `context.AddRange(...)`.
3. Сохраните изменения вызовом `context.SaveChanges()`.

 **Важно:** Чтобы изменения структуры применились, раскомментируйте строчку `context.Database.EnsureDeleted();` перед `EnsureCreated()` — это сбросит старую схему и пересоздаст таблицы начисто.


### Шаг 4. Файл `Queries/LinqDemos.cs` — Написание запросов LINQ
Напишите **минимум 5 запросов** по следующим обязательным критериям:

-  **1. Фильтрация (`Where`)**: Условие с несколькими параметрами (логические `&&`, `||`).
-  **2. Сортировка (`OrderBy`, `ThenBy` или `OrderByDescending`)**: Сортировка по возрастанию и убыванию.
- **3. Проекция (`Select`)**: Создание нового анонимного типа (`new { ... }`) только с нужными полями.
- **4. Агрегация (`Count`, `Sum`, `Average`, `Min`, `Max`)**: Подсчет аналитических показателей по базе.
-  **5. Группировка (`GroupBy`)**: Разбивка записей по категории/типу с агрегатным вычислением для каждой группы.
-  **6. Жадная загрузка связей (`Include`, `ThenInclude`)**: Запрос, подтягивающий связанные таблицы без вылета `NullReferenceException`.


### Шаг 5. Файл `Program.cs` — Точка сборки
Вызовите методы с вашими запросами по очереди в блоке `using (var db = new ...)`, чтобы на защите я мог мог видеть результаты выполнения в консоли.


## Часто возникающие вопросы (FAQ)

* **Где физически создается файл базы данных?**  
  В папке с исполняемым файлом: `bin/Debug/net.../university.db`.
* **Чем открыть базу данных SQLite для проверки?**  
  Используйте бесплатную программу [DB Browser for SQLite](https://sqlitebrowser.org/). В ней можно открыть созданный `.db` файл и увидеть структуру таблиц и сырые строки.
* **Ошибка: `SQLite Error 1: no such table...`**  
  Вы изменили модели, но база осталась старой. Удалите файл `university.db` из папки `bin/Debug/net...` или раскомментируйте `context.Database.EnsureDeleted()` в `DbInitializer.cs`.
